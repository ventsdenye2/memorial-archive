# Fight / Throw / Block / Death / Dodge 动作引用说明

本目录的 `player_01_fight_split.json` 是一个 Spine 骨骼文件，其中包含 10 个动画。
`SkeletonDataAsset` 负责保存整套骨骼、图集和全部动画，并不保存“默认播放哪个动画”。
因此没有复制十份内容完全相同的 `SkeletonDataAsset`；按动作引用应使用
`AnimationReferences` 目录中生成的 `AnimationReferenceAsset`。
