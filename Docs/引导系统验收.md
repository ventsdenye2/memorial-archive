# 引导系统验收

## 验收范围

本次验收覆盖前厅操作引导、灯具与黑暗规则、日记和地图解锁、系统菜单提示，以及治疗室到战斗场景的战斗教学链路。页面完成由玩家确认（`Acknowledge`）记录；实际业务事件负责触发页面或推进独立里程碑，二者分开验收。

用户已确认的回归范围包括：

- 前厅移动、背包、系统页面和战斗整页引导。
- 实际敌人攻击后触发闪避，再完成武器装备、战斗页面和敌人击杀。
- 玩家死亡后先播放战斗失败独白，再打开 Load 页面。
- 伤害管线击杀引导敌人并进入战斗完成阶段（phase 5）。

已确认 20 项 EditMode 测试通过。最新脚本驱动 PlayMode 证据包括：实际聚焦特殊灯并发布 InteractPressed 点亮；自然聚焦 `guide_first_diary` 并发布 InteractPressed 正常拾取、解锁 map；黑暗警告 1/2/3 依次出现，`dark_ending` 完成后再死亡；以及攻击→闪避→装备→战斗、死亡独白→Load、伤害击杀→phase 5 链路。这些验证通过事件和脚本推进，不能替代人工按键、人工操作 UI 和真实游玩验收。

## 页面确认与业务条件

页面是否完成，统一以玩家确认（`Acknowledge`）为准；页面出现、关闭和确认属于表现层流程。业务事件只决定页面何时请求，以及独立的业务里程碑是否记录，不能把业务事件当作页面确认。

## 教程整页映射

| 页面 ID | 整页内容/触发语义 | 暂停行为 | 完成方式 |
| --- | --- | --- | --- |
| `movement` | 前厅基础移动 | 不暂停 | 前厅进入延迟结束后请求，页面确认后记录完成 |
| `inventory` | “将背包物品拖拽至快捷栏，或选中物品点击装备按钮即可完成装备。” | 暂停 | 背包面板打开时请求，玩家确认页面（`Acknowledge`） |
| `light` | 特殊灯具操作与区域照明 | 暂停 | 聚焦特殊灯具时请求，玩家确认页面（`Acknowledge`）；区域点亮另行记录业务里程碑 `light_activated` |
| `systems` | 系统菜单操作 | 暂停 | 首次日记解锁地图且 Diary 关闭后请求，玩家确认页面（`Acknowledge`） |
| `combat` | 战斗整页说明 | 暂停 | 选中武器并完成战斗准备后请求，玩家确认页面（`Acknowledge`） |

以上 5 项（`movement`、`inventory`、`light`、`systems`、`combat`）是整页教程。`dodge`（“按空格闪避”）和 `equip`（“打开背包将武器装备至快捷栏并选中”）是暂停时显示的文字提示，不计入整页映射；两者同样以玩家确认页面为完成条件，业务事件负责推进后续阶段。

`GuideSystem` 在页面打开时按页面的 `pause` 设置 UI 暂停所有者；页面关闭或确认时释放暂停。`movement` 是唯一不暂停的整页，其他整页和文字提示均暂停输入。闪避提示使用 Space；背包页可在 Inventory 已打开时显示，避免暂停状态阻止背包操作。

## 教程触发与独白映射

普通灯具不触发特殊灯具教程；只有实际聚焦并交互特殊灯具时才触发 `light` 页面。越过装备门槛时，根据手提灯状态提示 `guide_obstacle` 或 `guide_need_lantern`。灯光不足时依次排队 `guide_dark_warning_1`、`guide_dark_warning_2`、`guide_dark_warning_3`，黑暗持续超过宽限时间后排队 `guide_dark_ending`。

首次日记解锁地图且 Diary 关闭后进入系统页引导；特殊灯具点亮时排队 `guide_lamp_diary`，不是由日记收集触发。自然交互路径为聚焦 `guide_first_diary` 日记并按 InteractPressed，完成拾取后解锁地图。治疗室取得关键物品并进入配置的战斗场景后排队 `guide_encounter`。引导敌人攻击、闪避、装备和战斗完成分别驱动 `dodge`、`equip`、`combat` 和 `combat_finished` 状态。

以下新增独白目前是占位文本，验收时只确认触发、顺序和 Load 门控，不验收最终文案：

- `guide_need_lantern`
- `guide_obstacle`
- `guide_lamp_diary`
- `guide_dark_warning_1`
- `guide_dark_warning_2`
- `guide_dark_warning_3`
- `guide_dark_ending`
- `guide_encounter`

死亡回归要求：战斗教学期间收到角色死亡事件后，先排队并播放 `guide_combat_defeat`；独白未播放完时关闭或阻止 Load，独白完成后才重新打开 Load。

## 手工新游戏回归

1. 从主菜单开始 New Game，确认前厅首次进入出现移动整页，确认时角色仍可移动。
2. 走到装备门槛附近，确认手提灯未点亮时出现需要手提灯提示；装备并点亮后可清除门槛。
3. 进入特殊灯具范围并按交互键，确认特殊灯具整页出现；确认页面后，检查区域点亮、`light_activated` 里程碑和手提灯燃料补充。
4. 聚焦 `guide_first_diary` 日记并按交互键，确认日记正常拾取并解锁地图；保持 Diary 关闭，确认系统整页随后出现并暂停游戏输入。
5. 进入治疗室取得关键物品，再进入配置的战斗场景；确认战斗独白后出现敌人。
6. 等待引导敌人实际攻击，确认闪避文字提示出现；执行闪避并确认提示，随后确认装备文字提示出现。
7. 打开背包，把武器放入快捷栏并选中；确认装备提示完成，战斗整页出现。
8. 使用真实伤害管线击杀引导敌人，确认战斗完成状态和胜利独白。
9. 在战斗教学期间让角色死亡，确认失败独白先于 Load 页面；独白结束后 Load 页面才可操作。

## 手工存档回归

1. 在移动、灯具、地图解锁、装备页和战斗各阶段分别建立存档，退出后从 Load 恢复。
2. 恢复后确认已完成页面不会重复排队，未完成页面和 pending 顺序保留；当前页面不会跨场景残留。
3. 在背包已打开时保存并恢复，确认 `inventory` 页面仍可正常显示，不被全局输入暂停永久阻塞。
4. 在战斗 phase 1（接近）、phase 2（等待闪避）、phase 3（装备）、phase 4（战斗）分别保存并恢复，确认阶段、敌人生命和装备门控继续有效。
5. 在死亡失败独白尚未结束时保存或恢复，确认不会绕过独白直接打开 Load；独白完成后可正常进入 Load。
6. 选择 New Game 后确认引导完成列表、pending 队列、战斗阶段和死亡等待状态全部清空。
