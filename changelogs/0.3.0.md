# 0.3.0

- Added a configuration-driven GuideSystem with sequential steps, parallel step
  groups, display delay, auto-hide, real-result completion conditions, required
  steps, and skip-tolerant progression.
- Added the GuideStepConfig / GuideSequenceConfig ScriptableObjects, GuideSaveData
  progress persistence, save/new-game reset wiring, and ConfigManager indexing.
- Added GuideStepStartedEvent / GuideStepCompletedEvent / GuideStepHiddenEvent;
  the GuideOverlayPanel view only reacts to these events and never advances steps.
- Added a non-modal GuideOverlay (registered alongside HUD via a shared
  IsNonModalOverlay check) so guidance never pauses the game or blocks movement.
- Added the operation guide use case (move / inventory / equip lantern / run /
  stamina) triggered on entering FrontHall, plus a one-shot
  Stage3GuideBootstrap editor tool that emits the sequence, step configs and the
  overlay prefab.
